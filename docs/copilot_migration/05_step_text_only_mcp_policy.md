# Шаг 4: Политики text-only и MCP tools

## Цель
Включить безопасный режим генерации: без file-edit/shell destructive инструментов, но с поддержкой MCP для research.

## Что реализовать
1. Добавить policy-конфиг:
- `text_only: true`
- `allow_mcp_tools: true`
- `allowed_mcp_servers: [...]`
2. В Copilot адаптере применить policy на каждую сессию/запрос.
3. Зафиксировать deny-правила для write/shell инструментов.

## Правила
1. По умолчанию все инструменты запрещены, кроме явно разрешенных.
2. Любой MCP вызов должен проходить через whitelist.
3. Любое изменение policy должно логироваться.

## Критерии успешности
1. Генерация текста работает.
2. MCP-инструменты из whitelist доступны.
3. Попытка file-edit/shell write отклоняется policy-слоем.

## Проверка
1. Позитивный тест: research-запрос с MCP доступом.
2. Негативный тест: запрос на редактирование файла должен быть отклонен.
3. Логи содержат маркер policy decision.

## Риски
1. Неполный whitelist может блокировать нужные сценарии.
2. Слишком широкий whitelist повышает риск.

## Решение рисков
1. Начать с минимального списка MCP серверов.
2. Расширять whitelist по запросу и через ревью.
