# План реализации (этап 1)

## Порядок шагов
1. Шаг 1: Ввести LLM Core контракты и конфиг маршрутизации.
2. Шаг 2: Реализовать интеграцию Copilot SDK (активный провайдер).
3. Шаг 3: Переключить pipeline обработчиков на новый gateway.
4. Шаг 4: Внедрить text-only policy и MCP whitelist.
5. Шаг 5: Подключить OpenRouter как standby провайдер.
6. Шаг 6: Добавить наблюдаемость, тесты и smoke-проверки.
7. Шаг 7: Провести rollout и зафиксировать критерии приемки.

## Принципы реализации
1. Сначала совместимость, затем оптимизация.
2. Любой новый слой должен иметь четкий контракт.
3. Никаких скрытых side effects в бизнес-логике.
4. Все критичные решения фиксировать логами.

## Обязательные требования ко всем шагам
1. Обновлять документацию при каждом архитектурном изменении.
2. Сохранять обратную совместимость внешнего поведения Telegram-бота.
3. Не включать destructive tools на этапе 1.
4. У каждого шага должна быть проверка успеха (DoD).
